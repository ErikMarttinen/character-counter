# Character Counter

A live character counter with a 280 character limit, like a social media post box.

**Live demo:** https://erikmarttinen.github.io/character-counter/

## Features
- Counts characters live as you type
- Turns red and shows "Text too long!" when you go over 280
- Clear button empties the box and resets the count

## Built with
- HTML
- CSS
- JavaScript (no libraries)

## What I learned
- Listening for the "input" event to update the page as the user types
- Using .length to count characters in a string
- Changing styles from JavaScript with .style.color
